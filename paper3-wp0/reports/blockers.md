# Blockers

1. G1: the Sherlock 01-Basic download has no grid model file (no pandapower net, no Wattson grid definition; `sherlock-config.yml` only names the scenario `cigre-mv`). Not worked around with mirrors. T7 instead tests a reconstruction from pandapower's CIGRE MV (all DER) using only data in the download. Owner approved fetching it; the public Wattson repository (fkie-cad/wattson, commit 839d4e4) holds only a generic CIGRE MV example, so Sherlock's scenario remains unavailable. The reconstruction is validated at the noise floor instead.
2. Transformer tap changer parameters: resolved by identification from data (HV side, 1.500 % per step, `sherlock_taps.md`). The real tap range beyond the positions used in the recording ([-1, 0]) is unknown (⟨·⟩). The reference CIGRE MV envelope still has no tap changer.
3. Sherlock switch indices 8 to 31 have no documented mapping. The mapping used (switch 8+2l = line l from end, 9+2l = to end) was inferred from the data and checked on 172 of 172 open switches.
